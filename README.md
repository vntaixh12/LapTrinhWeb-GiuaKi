# Bài kiểm tra giữa kì

Website cá nhân giới thiệu thông tin, kỹ năng, dự án và biểu mẫu liên hệ của Võ Anh Tài. Đây là bài kiểm tra giữa kì môn Lập trình Web.

## Chức năng

- Điều hướng đến các mục Giới thiệu, Kỹ năng, Dự án và Liên hệ.
- Hiển thị danh sách kỹ năng và dự án.
- Tải dữ liệu dự án từ `js/data.json`.
- Kiểm tra các trường bắt buộc trong biểu mẫu liên hệ.
- Chuyển đổi giao diện sáng/tối và lưu lựa chọn bằng `localStorage`.

> Biểu mẫu hiện chỉ kiểm tra thông tin ở phía trình duyệt; chức năng gửi dữ liệu lên máy chủ chưa được cấu hình.

## Công nghệ

- HTML5
- CSS3 và SCSS
- JavaScript
- JSON

## Chạy dự án

Mở thư mục dự án bằng Visual Studio Code và chạy `index.html` với tiện ích Live Server. Cần dùng máy chủ cục bộ để trình duyệt tải được dữ liệu từ `js/data.json`.

## Cấu trúc thư mục

```text
.
├── index.html
├── css/
│   ├── style.css
│   └── style.scss
└── js/
    ├── data.json
    └── script.js
```
